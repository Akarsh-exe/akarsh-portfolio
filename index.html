Selected Work

Music Player ↗ web · live

A browser-based audio and video player built entirely with vanilla JavaScript. Supports drag-and-drop file loading, a spinning vinyl UI, fullscreen video mode, shuffle and repeat, search, recent history, and OS-level media controls through the Media Session API. No dependencies, no bundler — a single HTML file deployed on Cloudflare Pages.

Music Player — Source ↗ open source

The full source code for the music player. Clean, readable vanilla JS with hand-rolled state management, custom SVG icons, and a neon visual theme.

YouTube Downloader cli tool

A command-line utility for downloading audio and video from YouTube with format selection, playlist support, and automatic metadata tagging. Built with Python and yt-dlp. Used daily as part of a personal media workflow.

Silent Blasts ↗ minecraft mod

A client-side Fabric mod for Minecraft 1.21.11 that filters specific blast sound events. Written in Java with Mixin and the Fabric API. Server-safe, no gameplay changes — published with a live download page.

Other Projects ↗ github
